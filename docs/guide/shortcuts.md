# Keyboard shortcuts

On Linux and Windows, use <kbd>Ctrl</kbd> where macOS uses <kbd>⌘</kbd>.

## Everywhere

| Shortcut | Action |
| --- | --- |
| <kbd>⌘K</kbd> | Command palette |
| <kbd>⌘P</kbd> | Go to a worktree or sub-agent |
| <kbd>⌘O</kbd> | Open project |
| <kbd>⌘N</kbd> | New worktree |
| <kbd>⌘,</kbd> | Settings |
| <kbd>⌘D</kbd> | Show diff |
| <kbd>⌘&#92;</kbd> | Open or close the right dock |
| <kbd>⌘⇧F</kbd> | Full-screen right dock |
| <kbd>⌘B</kbd> | Toggle sidebar |
| <kbd>⌘M</kbd> | Change model |
| <kbd>⌘.</kbd> | Stop agent |
| <kbd>⌃⌘F</kbd> (<kbd>F11</kbd>) | Toggle full screen |
| <kbd>⌘Q</kbd> | Quit |

## In the chat

| Shortcut | Action |
| --- | --- |
| <kbd>Enter</kbd> | Send, or steer while Pi works |
| <kbd>Page Up</kbd> / <kbd>Page Down</kbd> | Scroll a page |
| <kbd>Ctrl+U</kbd> / <kbd>Ctrl+D</kbd> | Scroll half a page |
| <kbd>⌘↓</kbd> (<kbd>Ctrl+End</kbd>) | Jump to the latest |

## In lists

In the command palette, the switcher and the slash menu:

| Shortcut | Action |
| --- | --- |
| <kbd>↑</kbd> <kbd>↓</kbd> or <kbd>Ctrl+P</kbd> <kbd>Ctrl+N</kbd> | Move up and down |
| <kbd>Enter</kbd> (<kbd>Tab</kbd> in the slash menu) | Pick |
| <kbd>⌘Enter</kbd> | Open the pick in the right dock (switcher) |
| <kbd>Esc</kbd> | Close |

## With the mouse

<kbd>⌘</kbd>-click a worktree or sub-agent in the sidebar to open it in the right dock.
